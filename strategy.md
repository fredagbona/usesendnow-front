# msgflash.com - Full Keyword Strategy

## The Big Picture

msgflash sits at the intersection of two distinct audiences:
1. **Developers & makers** - want a clean REST API, no Meta approval headaches, webhooks that just work
2. **WooCommerce store owners** - want WhatsApp cart recovery, order tracking, and higher coupon redemption

These are two different buyer journeys, two different sets of keywords, and they need to be treated separately. The `/wordpress` page already does this partially - but the homepage is currently trying to speak to everyone and ends up owning no one's attention in search.

---

## Cluster 1 - Developer & API Audience (Homepage + Docs)

These are the people who will sign up and integrate immediately. High intent, low competition for the specific terms msgflash can own.

### Priority Keywords

| Keyword | Type | Why |
|---|---|---|
| `WhatsApp API without Meta approval` | Problem-aware | #1 pain point in the market. Nobody wants BSP approval. |
| `WhatsApp API for developers` | Direct match | Your core audience, typed into Google every day |
| `send WhatsApp messages via REST API` | Tutorial / how-to | High organic volume, easy to rank with a docs or blog post |
| `WhatsApp webhook integration` | Long-tail | Dev audience, very specific, converts well |
| `WhatsApp automation API no BSP` | Problem-aware | Competitors own "BSP" keywords - you can own the anti-BSP angle |
| `WhatsApp API for n8n / Zapier / Make` | Tool-specific | Your homepage already mentions these - match the keywords |
| `self-hosted WhatsApp API` | Niche | Smaller volume but very high intent |
| `WhatsApp QR code API` | Feature-specific | Your onboarding uses QR - mention it in copy and rank for it |

### Content to Create

- **Blog post:** "How to send WhatsApp messages via REST API without Meta approval" → targets the #1 pain point, links to docs, converts to free signup
- **Blog post:** "msgflash vs WATI - why makers choose a simple API over BSP platforms" → comparison content ranks fast, intercepts competitor-branded searches
- **Docs landing page SEO:** Make `docs.msgflash.com` indexable with proper titles and descriptions per endpoint

---

## Cluster 2 - WooCommerce Store Owner Audience (/wordpress page)

These are buyers, not builders. They want results (more revenue, fewer support tickets), not API specs. The `/wordpress` page is currently under-optimized for the keywords this audience actually searches.

### Priority Keywords

| Keyword | Type | Why |
|---|---|---|
| `WooCommerce WhatsApp plugin` | Category keyword | High volume, direct match to what you've built |
| `WooCommerce abandoned cart WhatsApp` | Problem-aware | Store owners search this exact phrase |
| `WhatsApp order notifications WooCommerce` | Feature keyword | The #2 use case on your page |
| `recover abandoned cart WhatsApp WooCommerce` | Long-tail | High buyer intent, lower competition |
| `free WooCommerce WhatsApp plugin` | Offer keyword | You're free - own this |
| `WooCommerce WhatsApp cart recovery plugin` | Long-tail | Very specific, very high intent |
| `increase coupon redemption WooCommerce WhatsApp` | Outcome keyword | Niche but zero competition |

### Page Changes for /wordpress

1. **H1 rewrite:** Current: "The old WooCommerce marketing playbook is dead. Recover 15% of your revenue via WhatsApp." → Better: "The Free WooCommerce WhatsApp Plugin for Abandoned Cart Recovery & Order Notifications"
2. **H2 additions:** Add keyword-rich subheadings like "Recover Abandoned Carts on WhatsApp - Automatically" and "Send WooCommerce Order Notifications via WhatsApp"
3. **Meta title:** `Free WooCommerce WhatsApp Plugin - Cart Recovery, Order Tracking & Lead Magnets | msgflash`
4. **Meta description:** `Recover abandoned carts, send order tracking messages, and boost coupon usage 3x - all via WhatsApp. Free WooCommerce plugin by msgflash. Setup in under 5 minutes.`
5. **Translate French steps** - Steps 01, 02, 03 are in French. This is costing you every English-language WooCommerce store owner who bounces.

## Cluster 3 - Campaign & Broadcast Audience (New landing page)

This audience isn't served by the current site at all. These are marketers and growth teams who want WhatsApp broadcast campaigns - not API access, not WooCommerce. They search differently.

### Priority Keywords

| Keyword | Type | Why |
|---|---|---|
| `WhatsApp broadcast campaign tool` | Category | High volume, underserved by API-focused tools |
| `send WhatsApp campaigns without Meta` | Problem-aware | Same anti-BSP angle, different audience |
| `WhatsApp bulk messaging tool` | Feature keyword | Broad, high volume |
| `WhatsApp marketing automation` | Category | Contested but worth owning a corner of |
| `WhatsApp campaign analytics` | Feature keyword | Differentiator if you offer reporting |

### What to Build

A dedicated `/campaigns` or `/broadcast` landing page targeting this cluster. The homepage mentions campaigns briefly but never builds a case for it. A focused page would rank independently and convert a third audience segment.

---

## Cluster 4 - Competitor Interception (Blog)

This is where fast wins come from. Competitor-branded searches are high intent and comparisons rank quickly.

| Target Search | Content to Create |
|---|---|
| `WATI alternatives` | "5 WATI alternatives for developers who want a simple API" |
| `AiSensy alternatives` | "AiSensy vs msgflash - WhatsApp API comparison" |
| `WhatsApp Business API alternatives 2026` | Already a hot search term (periskope.app is ranking for it) - you can too |
| `Gupshup alternatives for small business` | Niche, low competition, high intent |

**Why this works:** People searching for alternatives are already sold on WhatsApp automation. They just haven't picked a tool. You intercept them at the decision point.
