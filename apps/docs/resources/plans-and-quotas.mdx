MsgFlash offers two paid plans and no Free plan.

| | Starter | Growth |
| --- | ---: | ---: |
| Monthly price | €19 | €39 |
| Trial | 7 days | 7 days |
| WhatsApp instances | 5 | 20 |
| API keys | 5 | 10 |
| Webhook endpoints | 15 | 50 |
| Contact groups | 50 | Unlimited |
| Messages/month | 50,000 | 150,000 |
| API requests/month | 150,000 | 500,000 |
| Owned teams | 2 | 4 |
| Seats/team | 4 | 8 |

## Trial and access

- A billing account can consume one 7-day application-managed trial.
- Password signup accepts `trialPlanCode: "starter" | "growth"`; the default is `starter`.
- Google signup starts a Starter trial.
- The Dodo Payments trial setting must remain disabled because MsgFlash owns the trial clock.
- At trial expiry, unpaid accounts become non-operational. There is no automatic fallback plan.
- Cancellation keeps access until period end, then blocks product operations.
- A failed renewal can expose a 72-hour `past_due_grace`; use the returned `access` object rather than calculating it in the browser.

## Usage counting

Outbound usage counts accepted messages only. WhatsApp Statuses are removed. API requests are metered separately. Listing and detail responses expose current counters and plan limits so clients can show warnings before hard quota errors.
