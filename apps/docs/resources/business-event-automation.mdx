MsgFlash is evolving from a WhatsApp sending platform into **Business Event Automation**.

Businesses already produce events such as orders, payments, bookings, signups, subscriptions, and shipments. MsgFlash connects those events to automatic, traceable WhatsApp communication.

## What remains available

Instances, contacts and groups, templates, campaigns, scheduling, the Public API, API keys, webhooks, number lookup, teams, billing, usage tracking, and media remain core MsgFlash capabilities.

## Progressive rollout

Industry Templates, the Integration Gallery, customer Event Logs, expanded Delivery Analytics, the new Health Center, and business-aware onboarding will be introduced progressively. They are not all available today.

## Plans and access

MsgFlash provides one seven-day trial on **Starter at €19/month** or **Growth at €39/month**. There is no permanent Free plan. If a trial ends without an active subscription, product operations are blocked while billing, profile, and eligible exports remain accessible.

The Public API remains first-class. MsgFlash stays focused on WhatsApp communication and will not become a generic workflow builder.
