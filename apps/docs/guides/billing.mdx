## Product rules

MsgFlash has two paid plans: Starter at €19/month and Growth at €39/month. A new billing account gets one 7-day trial on the selected plan. There is no Free plan and an unpaid account is blocked after its trial.

## Frontend flow

1. Send `trialPlanCode: "starter" | "growth"` to `POST /api/auth/signup`. Omit it to select Starter.
2. Read `GET /api/billing/subscription` after authentication.
3. Treat `data.access.operational` as the access source of truth.
4. If access is blocked, redirect product routes to `/billing` while keeping billing, profile, account deletion, and contact export available.
5. Start checkout with `POST /api/billing/checkout` and `planCode: "starter" | "growth"`.
6. Refetch subscription state after returning from Dodo Payments. Do not mark an account paid from the browser return URL alone.

## Access handling

| Reason | Operational | Recommended UI |
| --- | --- | --- |
| `active`, `trialing`, `cancellation_grace`, `past_due_grace` | yes | Show remaining trial/period/grace time |
| `trial_expired`, `payment_required` | no | Billing paywall and plan selection |
| `past_due` | no | Payment recovery screen |
| `suspended` | no | Contact support; do not offer a client-side bypass |

Product API calls may return `402 TRIAL_EXPIRED`, `402 SUBSCRIPTION_REQUIRED`, `402 SUBSCRIPTION_PAST_DUE`, or `403 SUBSCRIPTION_SUSPENDED`. Preserve the current route when redirecting so the user can resume after payment.

## Dodo Payments

Create one recurring monthly product for Starter (€19) and one for Growth (€39). Configure their product IDs as `DODO_PRODUCT_ID_STARTER` and `DODO_PRODUCT_ID_GROWTH`. Disable provider-side trials. Webhooks, not return URLs, activate subscriptions and record payments.

Configure the backend with `DODO_PAYMENTS_ENVIRONMENT`, `DODO_PAYMENTS_API_KEY`, `DODO_PAYMENTS_WEBHOOK_KEY`, `DODO_PRODUCT_ID_STARTER`, and `DODO_PRODUCT_ID_GROWTH`. Test credentials and product IDs must only be used with `test_mode`; production credentials and product IDs must only be used with `live_mode`.

Register `https://srv.msgflash.com/api/payments/webhook/dodo` as the Dodo webhook URL, replacing the host if the backend public URL differs for the target environment.

## Cancellation and downgrade

Growth can be downgraded to Starter at period end. Cancellation also applies at period end. Once effective, cancellation produces an expired, non-operational account; it never creates a Free subscription.
