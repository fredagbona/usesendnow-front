MsgFlash propose deux plans payants et aucun plan Free.

| | Starter | Growth |
| --- | ---: | ---: |
| Prix mensuel | 19 € | 39 € |
| Essai | 7 jours | 7 jours |
| Instances WhatsApp | 5 | 20 |
| Clés API | 5 | 10 |
| Endpoints webhook | 15 | 50 |
| Groupes de contacts | 50 | Illimités |
| Messages/mois | 50 000 | 150 000 |
| Requêtes API/mois | 150 000 | 500 000 |
| Équipes possédées | 2 | 4 |
| Sièges/équipe | 4 | 8 |

## Essai et accès

- Un compte de facturation ne peut consommer qu'un seul essai applicatif de 7 jours.
- L'inscription par mot de passe accepte `trialPlanCode: "starter" | "growth"` ; la valeur par défaut est `starter`.
- L'inscription Google démarre un essai Starter.
- L'option trial de Dodo Payments doit rester désactivée car MsgFlash possède l'horloge d'essai.
- À l'expiration, un compte non payé devient non opérationnel. Aucun plan de repli n'est appliqué.
- Une résiliation conserve l'accès jusqu'à la fin de période puis bloque les opérations produit.
- Un renouvellement échoué peut ouvrir une grâce `past_due_grace` de 72 heures ; le frontend doit lire l'objet `access` plutôt que recalculer l'état.

## Comptage de l'usage

L'usage outbound compte uniquement les messages acceptés. Les statuts WhatsApp sont supprimés. Les requêtes API sont comptées séparément. Les réponses de facturation exposent les compteurs et les limites pour afficher des alertes avant les erreurs de quota.
