---
title: FAQ
description: Questions fréquentes sur MsgFlash, les plans, les clés API et les webhooks.
---

<AccordionGroup>
  <Accordion title="MsgFlash utilise-t-il l'API officielle WhatsApp Business ?">
    Non. MsgFlash s'appuie sur Evolution API v2 comme provider interne, pas sur l'API Cloud officielle Meta.
  </Accordion>

  <Accordion title="Puis-je utiliser un numéro WhatsApp existant ?">
    Oui. Vous connectez un numéro existant via QR code ou pairing code depuis le dashboard.
  </Accordion>

  <Accordion title="Comment intégrer avec Make, n8n ou Zapier ?">
    Utilisez un module HTTP standard vers `https://srv.msgflash.com/api/v1/*` avec le header `x-api-key: votre_cle_api`.
  </Accordion>

  <Accordion title="Puis-je avoir plusieurs clés API ?">
    Oui, selon votre plan.
    Free: 1, Starter: 3, Pro: 10, Plus: 10.
  </Accordion>

  <Accordion title="Que faire si ma clé API est compromise ?">
    Révoquez-la immédiatement dans le dashboard, puis créez-en une nouvelle et mettez vos intégrations à jour.
  </Accordion>

  <Accordion title="Que se passe-t-il quand j'annule mon abonnement ?">
    L'abonnement reste exploitable jusqu'à la fin de la période en cours, puis le compte revient sur le plan Free et ses limites.
  </Accordion>

  <Accordion title="Quelle est la différence entre l'espace personnel et l'équipe ?">
    L'espace personnel suit votre plan et vos instances. L'espace équipe suit le plan et les instances du **propriétaire d'équipe** (avec assignations pour les collaborateurs). Changez le contexte actif dans le portail une fois l'UI reliée aux API équipes.
  </Accordion>

  <Accordion title="Qui paie les messages envoyés dans une équipe ?">
    La consommation sortante est imputée à l'abonnement du **propriétaire d'équipe** pour le mois en cours.
  </Accordion>

  <Accordion title="Clé API d'équipe vs clé personnelle ?">
    Les clés personnelles commencent par `msgf_live_` et n'accèdent qu'à votre espace personnel. Les clés d'équipe commencent par `msgf_team_` et exigent l'en-tête `X-Team-Id` correspondant à l'équipe. On ne les mélange pas.
  </Accordion>
</AccordionGroup>
