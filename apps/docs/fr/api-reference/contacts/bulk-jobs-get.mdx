---
title: GET Détail d'un job bulk contacts
description: Retourne le détail d'un job asynchrone bulk contacts.
---

## Endpoint

```txt
GET /api/v1/contacts/bulk-jobs/{jobId}
```

## Paramètres

| Champ | Type | Requis | Emplacement | Description |
|---|---|---:|---|---|
| `jobId` | UUID | oui | path | ID du job bulk |
