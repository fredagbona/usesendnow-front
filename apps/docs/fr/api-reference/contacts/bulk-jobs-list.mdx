---
title: GET Lister les jobs bulk contacts
description: Liste les jobs asynchrones récents déclenchés par les opérations bulk sur les contacts.
---

## Endpoint

```txt
GET /api/v1/contacts/bulk-jobs
```

## Paramètres query

| Champ | Type | Requis | Description |
|---|---|---|---|
| `limit` | integer | non | Taille de page, défaut `20`, max `100` |
| `cursor` | UUID | non | Curseur de pagination |
