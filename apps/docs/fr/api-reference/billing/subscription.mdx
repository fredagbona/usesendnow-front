---
title: GET Abonnement courant
description: Retourne l'abonnement, l'accès effectif, l'usage et la période.
---

## Endpoint

```txt
GET /api/v1/billing/subscription
```

```json
{
  "data": {
    "subscription": {
      "status": "trialing",
      "plan": { "code": "starter", "name": "Starter" },
      "trialPlanCode": "starter",
      "trialStartedAt": "2026-07-14T09:00:00.000Z",
      "trialEndsAt": "2026-07-21T09:00:00.000Z",
      "trialConsumedAt": "2026-07-14T09:00:00.000Z",
      "scheduledPlan": null,
      "scheduledPlanAt": null,
      "scheduledAction": null
    },
    "access": {
      "operational": true,
      "reason": "trialing",
      "blockedAt": null,
      "graceEndsAt": null
    },
    "usage": {
      "messagesCount": 0,
      "effectiveOutboundUsage": 0,
      "apiRequestsCount": 0,
      "activeInstancesCount": 0,
      "activeApiKeysCount": 0
    },
    "period": {
      "start": "2026-07-14T09:00:00.000Z",
      "end": "2026-07-21T09:00:00.000Z"
    }
  }
}
```

`access.operational` est la source de vérité du frontend. Les raisons possibles sont `active`, `trialing`, `cancellation_grace`, `past_due_grace`, `trial_expired`, `payment_required`, `past_due` et `suspended`.

Si l'accès est bloqué, les endpoints produit répondent `402` (`TRIAL_EXPIRED`, `SUBSCRIPTION_REQUIRED` ou `SUBSCRIPTION_PAST_DUE`) ou `403 SUBSCRIPTION_SUSPENDED`. La facturation, le profil, la suppression du compte et l'export des contacts restent accessibles dans le portail.

<Note>`statusesCount` peut encore apparaître temporairement pour compatibilité. Les statuts WhatsApp sont supprimés et ne contribuent jamais à `effectiveOutboundUsage`.</Note>
