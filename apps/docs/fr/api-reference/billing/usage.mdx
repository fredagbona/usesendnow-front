---
title: GET Usage de facturation
description: Retourne l'usage mensuel et l'accès effectif du compte.
---

## Endpoint

```txt
GET /api/v1/billing/usage
```

```json
{
  "data": {
    "plan": { "code": "starter", "name": "Starter" },
    "access": { "operational": true, "reason": "active", "blockedAt": null, "graceEndsAt": null },
    "usage": {
      "messagesCount": 1250,
      "effectiveOutboundUsage": 1250,
      "apiRequestsCount": 8400,
      "activeInstancesCount": 2,
      "activeApiKeysCount": 1
    },
    "period": { "start": "2026-07-01T00:00:00.000Z", "end": "2026-07-31T23:59:59.999Z" }
  }
}
```

`effectiveOutboundUsage` est égal à `messagesCount`. Les statuts WhatsApp ne sont ni supportés ni facturés. L'usage est suivi par compte de facturation et reste disponible dans le portail via `GET /api/billing/subscription`.
