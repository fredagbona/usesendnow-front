---
title: GET Lister les plans
description: Retourne les plans actifs Starter et Growth.
---

## Endpoint

```txt
GET /api/v1/billing/plans
```

Cet endpoint en lecture seule retourne les deux plans actifs. Les prix sont mensuels et exprimés en EUR. Il n'existe plus de plan Free.

| Code | Prix | Instances | Clés API | Webhooks | Groupes | Messages/mois | Requêtes API/mois | Équipes/sièges |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `starter` | 19 € | 5 | 5 | 15 | 50 | 50 000 | 150 000 | 2 / 4 |
| `growth` | 39 € | 20 | 10 | 50 | Illimités | 150 000 | 500 000 | 4 / 8 |

```json
{
  "data": [
    {
      "code": "starter",
      "name": "Starter",
      "priceEur": 19,
      "limits": {
        "maxInstances": 5,
        "maxApiKeys": 5,
        "maxWebhookEndpoints": 15,
        "maxContactGroups": 50,
        "monthlyOutboundQuota": 50000,
        "monthlyApiRequestQuota": 150000
      },
      "features": {
        "campaigns": true,
        "statuses": false,
        "voiceNotes": true,
        "webhooks": true,
        "numberLookups": true
      }
    }
  ]
}
```

<Note>Chaque nouveau compte bénéficie d'un seul essai de 7 jours sur le plan choisi à l'inscription. Google démarre un essai Starter.</Note>
