---
title: GET Lister les plans
description: Retourne le catalogue des plans MsgFlash actifs (EUR).
---

## Endpoint

```txt
GET /api/v1/billing/plans
```

## Réponse succès `200`

Plans actifs : **free**, **pro**, **max**. Prix en **EUR** (`priceEur`). Pas de FCFA sur cet endpoint.
