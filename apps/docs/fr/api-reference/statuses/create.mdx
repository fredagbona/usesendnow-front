---
title: Endpoint de statuts retiré
description: POST /api/v1/statuses ne fait plus partie de l'API publique supportée.
---

`POST /api/v1/statuses` est retiré. Les nouvelles intégrations ne doivent pas l'appeler. Les statuts WhatsApp ne sont inclus dans aucun plan et ne comptent pas dans l'usage outbound.

Utilisez [`POST /api/v1/messages/send`](/fr/api-reference/messages/send) ou les campagnes.
