---
title: POST Pause a campaign
description: Pause a campaign when its status allows it.
---

## Endpoint

```txt
POST /api/v1/campaigns/{id}/pause
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | Campaign ID |

Pas de body.

## Common errors

| HTTP | Code | When |
|---|---|---|
| `400` | `BAD_REQUEST` | Status incompatible avec la pause |
| `404` | `NOT_FOUND` | Campaign not found |
