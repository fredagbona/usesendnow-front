---
title: POST Resume a campaign
description: Resume a paused campaign.
---

## Endpoint

```txt
POST /api/v1/campaigns/{id}/resume
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | Campaign ID |
