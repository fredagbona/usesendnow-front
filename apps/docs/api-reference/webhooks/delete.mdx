---
title: DELETE Delete a webhook
description: Delete an existing webhook endpoint.
---

## Endpoint

```txt
DELETE /api/v1/webhooks/{id}
```

## Paramètres path

| Nom | Type | Requis | Description |
|---|---|---|---|
| `id` | UUID | oui | ID du webhook |

## Réponse succès `200`

```json
{
  "data": {
    "deleted": true
  }
}
```
