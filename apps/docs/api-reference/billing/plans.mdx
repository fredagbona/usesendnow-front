---
title: GET List plans
description: Return the active Starter and Growth plans.
---

## Endpoint

```txt
GET /api/v1/billing/plans
```

This read-only endpoint returns the two active plans. Prices are monthly and expressed in EUR. There is no Free plan.

| Code | Price | Instances | API keys | Webhooks | Contact groups | Messages/month | API requests/month | Teams/seats |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `starter` | €19 | 5 | 5 | 15 | 50 | 50,000 | 150,000 | 2 / 4 |
| `growth` | €39 | 20 | 10 | 50 | Unlimited | 150,000 | 500,000 | 4 / 8 |

```json
{
  "data": [
    {
      "code": "starter",
      "name": "Starter",
      "priceEur": 19,
      "limits": {
        "maxInstances": 5,
        "maxApiKeys": 5,
        "maxWebhookEndpoints": 15,
        "maxContactGroups": 50,
        "monthlyOutboundQuota": 50000,
        "monthlyApiRequestQuota": 150000
      },
      "features": {
        "campaigns": true,
        "statuses": false,
        "voiceNotes": true,
        "webhooks": true,
        "numberLookups": true
      }
    }
  ]
}
```

<Note>New accounts receive one 7-day trial on the plan selected at signup. Google signup starts a Starter trial.</Note>
