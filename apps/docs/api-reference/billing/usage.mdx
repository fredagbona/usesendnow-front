---
title: GET Billing usage
description: Return monthly usage and effective account access.
---

## Endpoint

```txt
GET /api/v1/billing/usage
```

```json
{
  "data": {
    "plan": { "code": "starter", "name": "Starter" },
    "access": { "operational": true, "reason": "active", "blockedAt": null, "graceEndsAt": null },
    "usage": {
      "messagesCount": 1250,
      "effectiveOutboundUsage": 1250,
      "apiRequestsCount": 8400,
      "activeInstancesCount": 2,
      "activeApiKeysCount": 1
    },
    "period": { "start": "2026-07-01T00:00:00.000Z", "end": "2026-07-31T23:59:59.999Z" }
  }
}
```

`effectiveOutboundUsage` equals `messagesCount`. WhatsApp Statuses are not supported or billed. Usage is tracked per billing account and is also available to the portal through `GET /api/billing/subscription`.
