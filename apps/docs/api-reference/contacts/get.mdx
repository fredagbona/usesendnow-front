---
title: GET Retrieve a contact
description: Retrieve contact details.
---

## Endpoint

```txt
GET /api/v1/contacts/{id}
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | ID du contact |

## Success response `200`

```json
{
  "data": {
    "id": "cnt_uuid",
    "name": "Awa Doe",
    "phone": "+33612345000"
  }
}
```
