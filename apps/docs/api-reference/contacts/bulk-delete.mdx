---
title: POST Bulk delete contacts
description: Delete multiple contacts in a single request.
---

## Endpoint

```txt
POST /api/v1/contacts/bulk-delete
```

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `contactIds` | UUID[] | yes | 1 à 500 IDs |

## Success response `200`

```json
{
  "data": {
    "requested": 2,
    "deleted": 1,
    "notFound": ["cnt_missing"]
  }
}
```
