---
title: POST Create a contact
description: Create a contact in your MsgFlash directory.
---

## Endpoint

```txt
POST /api/v1/contacts
```

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | string | yes | Nom complet |
| `phone` | string | yes | E.164 number |
| `tags` | string[] | no | Tags |
| `meta` | object | no | Métadonnées |

## Success response `201`

```json
{
  "data": {
    "id": "cnt_uuid",
    "name": "Awa Doe",
    "phone": "+33612345000"
  }
}
```
