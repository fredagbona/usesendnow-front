---
title: GET List bulk contact jobs
description: List recent asynchronous bulk jobs triggered from contact bulk operations.
---

## Endpoint

```txt
GET /api/v1/contacts/bulk-jobs
```

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `limit` | integer | no | Page size, default `20`, max `100` |
| `cursor` | UUID | no | Cursor for pagination |
