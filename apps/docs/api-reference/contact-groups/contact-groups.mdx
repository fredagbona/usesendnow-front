---
title: GET List groups for a contact
description: List the groups a contact belongs to.
---

## Endpoint

```txt
GET /api/v1/contacts/{id}/groups
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | ID du contact |

## Success response `200`

```json
{
  "data": {
    "groups": [
      {
        "id": "grp_uuid",
        "name": "Clients VIP",
        "color": "#F59E0B"
      }
    ]
  }
}
```
