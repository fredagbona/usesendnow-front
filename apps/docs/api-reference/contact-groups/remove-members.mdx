---
title: DELETE Remove members
description: Remove multiple contacts from a group.
---

## Endpoint

```txt
DELETE /api/v1/contacts/groups/{groupId}/members
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `groupId` | UUID | yes | Group ID |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `contactIds` | UUID[] | yes | Contacts à retirer |

## Success response `200`

```json
{
  "data": {
    "removed": 1,
    "notInGroup": 1
  }
}
```
