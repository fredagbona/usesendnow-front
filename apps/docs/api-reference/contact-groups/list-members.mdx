---
title: GET List group members
description: List group members with pagination and search.
---

## Endpoint

```txt
GET /api/v1/contacts/groups/{groupId}/members
```

## Parameters

| Nom | Type | Required | Location | Description |
|---|---|---|---|---|
| `groupId` | UUID | yes | path | Group ID |
| `limit` | integer | no | query | Taille de page |
| `cursor` | string | no | query | Curseur |
| `search` | string | no | query | Recherche sur nom ou téléphone |

## Success response `200`

```json
{
  "data": {
    "contacts": [],
    "nextCursor": null,
    "hasMore": false,
    "total": 0
  }
}
```
