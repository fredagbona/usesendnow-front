---
title: POST Add members
description: Add multiple contacts to a group.
---

## Endpoint

```txt
POST /api/v1/contacts/groups/{groupId}/members
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `groupId` | UUID | yes | Group ID |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `contactIds` | UUID[] | yes | Contacts à ajouter |

## Success response `200`

```json
{
  "data": {
    "added": 2,
    "alreadyInGroup": 0,
    "notFound": 0,
    "total": 2
  }
}
```
