---
title: GET Retrieve a group
description: Retrieve contact group details.
---

## Endpoint

```txt
GET /api/v1/contacts/groups/{groupId}
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `groupId` | UUID | yes | Group ID |

## Success response `200`

```json
{
  "data": {
    "id": "grp_uuid",
    "name": "Clients VIP",
    "contactCount": 12
  }
}
```
