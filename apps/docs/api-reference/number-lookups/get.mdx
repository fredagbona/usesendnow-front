---
title: GET Lookup details
description: Return status, metrics, and results for a number lookup.
---

## Endpoint

```txt
GET /api/v1/number-lookups/{id}
```

## Parameters

| Field | Type | Required | Location | Description |
|---|---|---:|---|---|
| `id` | UUID | yes | path | ID de la vérification |
