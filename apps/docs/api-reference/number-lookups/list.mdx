---
title: GET List lookups
description: List number lookups already created on your account.
---

## Endpoint

```txt
GET /api/v1/number-lookups
```

## Query params

| Paramètre | Type | Requis | Description |
|---|---|---:|---|
| `limit` | integer | non | Taille de page |
| `cursor` | UUID | non | Curseur de pagination |

## Réponse succès `200`

```json
{
  "data": {
    "lookups": [],
    "nextCursor": null,
    "hasMore": false
  }
}
```
