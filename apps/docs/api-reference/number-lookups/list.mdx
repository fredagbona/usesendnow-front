---
title: GET List lookups
description: List number lookups already created on your account.
---

## Endpoint

```txt
GET /api/v1/number-lookups
```

## Query params

| Parameter | Type | Required | Description |
|---|---|---:|---|
| `limit` | integer | no | Taille de page |
| `cursor` | UUID | no | Curseur de pagination |

## Success response `200`

```json
{
  "data": {
    "lookups": [],
    "nextCursor": null,
    "hasMore": false
  }
}
```
