---
title: DELETE Delete a template
description: Delete a template from your account.
---

## Endpoint

```txt
DELETE /api/v1/templates/{id}
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | ID du template |

## Success response `200`

```json
{
  "data": {
    "deleted": true
  }
}
```
