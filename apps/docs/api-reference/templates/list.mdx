---
title: GET List templates
description: List account templates with simple pagination.
---

## Endpoint

```txt
GET /api/v1/templates
```

## Parameters query

| Nom | Type | Required | Description |
|---|---|---|---|
| `page` | integer | no | Défaut `1` |
| `limit` | integer | no | Défaut `20`, max `100` |

## Success response `200`

```json
{
  "data": {
    "templates": [],
    "total": 0
  }
}
```
