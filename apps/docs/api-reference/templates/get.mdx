---
title: GET Retrieve a template
description: Retrieve template details.
---

## Endpoint

```txt
GET /api/v1/templates/{id}
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | ID du template |

## Success response `200`

```json
{
  "data": {
    "id": "tmpl_uuid",
    "name": "Relance panier",
    "type": "text",
    "variables": ["contact.firstName", "custom.code"]
  }
}
```
