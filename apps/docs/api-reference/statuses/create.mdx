---
title: Status endpoint retired
description: POST /api/v1/statuses is not part of the supported public API.
---

`POST /api/v1/statuses` is retired. Do not call it from new integrations. WhatsApp Statuses are not included in any current plan and are not counted in outbound usage.

Use [`POST /api/v1/messages/send`](/api-reference/messages/send) or campaigns instead.
