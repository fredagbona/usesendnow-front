---
title: GET Retrieve a message
description: Retrieve message details by message ID.
---

## Endpoint

```txt
GET /api/v1/messages/{id}
```

## Parameters path

| Nom | Type | Required | Description |
|---|---|---|---|
| `id` | UUID | yes | ID du message |
